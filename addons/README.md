# Add-ons

Minecraft Bedrock add-ons belong here.

Keep editable source files in this directory. When an add-on is ready for players, publish a packaged `.mcaddon` or `.mcpack` file through GitHub Releases where appropriate.

Recommended structure:

```text
addons/
└── addon-name/
    ├── README.md
    ├── behavior-pack/
    └── resource-pack/
```

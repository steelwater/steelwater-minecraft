# steelwater-minecraft

Minecraft skins, add-ons, worlds, and community creations by Steelwater.

This repository is the public home for Minecraft creations made by Dan and Huni, beginning with custom skins and expanding into add-ons, worlds, and other Bedrock Edition content.

## Contents

### Skins

Browse downloadable Minecraft skins in [`skins/`](./skins/).

### Add-ons

Minecraft Bedrock add-ons and related source files live in [`addons/`](./addons/).

### Worlds

Custom Minecraft worlds and map projects live in [`worlds/`](./worlds/).

### Documentation

Installation notes, contribution information, and other project documentation live in [`docs/`](./docs/).

## Downloads

Individual skins can be downloaded directly from their folders. Packaged add-ons and worlds can be published through GitHub Releases as the collection grows.

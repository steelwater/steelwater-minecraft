# steelwater-minecraft

Minecraft skins, add-ons, worlds, and community creations by Steelwater.

This repository is the public home for Minecraft creations made by Dan and Huni, beginning with custom skins and expanding into add-ons, worlds, and other Bedrock Edition content.

## Contents

### Skins

Browse downloadable Minecraft skins in [`skins/`](./skins/).

### Add-ons

Minecraft Bedrock add-ons and related source files live in [`addons/`](./addons/).

### Worlds

Custom Minecraft worlds and map projects live in [`worlds/`](./worlds/).

### Documentation

Installation notes, contribution information, and other project documentation live in [`docs/`](./docs/).

## Android add-on launcher

The optional [Steelwater Add-on Launcher](tools/android-addon-launcher/README.md) opens a selected `.mcaddon` in the installed Android Minecraft app. Pending copies survive screen rotation; interrupted imports offer a retry. See its guide for build, installation, privacy, and testing limitations.

## Project status

Underground Tech Pack follows the [project roadmap](https://docs.google.com/document/d/1CPZ1EgoX2-QF5DlEAsDjBctHagWDV2a0npEUHUG3n9c/edit). The [Core Metal Building Set](addons/underground-tech-pack/README.md) now contains eight decorative blocks in an unreleased M1 development build; Android acceptance remains pending. The launcher is a separate utility from merged [PR #2](https://github.com/steelwater/steelwater-minecraft/pull/2), with its deferred device checks bundled into M1 testing. See [CHANGELOG.md](CHANGELOG.md) for meaningful changes.
